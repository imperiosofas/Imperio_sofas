## Achados adicionais corrigidos

- **Redefinir senha sem senha atual** (`/conta/redefinir-senha`): qualquer sessão aberta (inclusive roubada) trocava a senha. Agora a página só abre com o cookie `pw_recovery` (HttpOnly, 15 min, com o id do usuário) criado ao validar o link de recuperação, nos fluxos `token_hash` e PKCE; sem ele, ou se for de outro usuário, vai para `/conta/seguranca`, que pede a senha atual. Observação: a troca em si é feita pelo navegador via Supabase, então a garantia final é ligar "Secure password change" no painel.
- **Pagamento sem aceite dos termos**: um cliente podia criar o pedido chamando o banco direto e pagar sem aceite registrado. `startOrderPayment` agora exige `terms_accepted_at`; se gravar o aceite falhar, o checkout mostra erro e o reenvio reaproveita o mesmo pedido (mesma chave de idempotência).

## Aceitos / não alterados (com justificativa)

- **Timestamp da assinatura do webhook**: não foi limitado. O Mercado Pago reenvia notificações por horas; um limite de tempo poderia descartar reenvios legítimos, e reenvios maliciosos são inofensivos (o pagamento é consultado na API com o token da loja e o evento é deduplicado).
- **CSP completa (`script-src` com nonce)**: exige tornar páginas dinâmicas e testar GSAP/framer-motion e o Checkout Pro; registrado em REMAINING_TASKS.
- **MFA**: mantida a decisão de não exigir MFA para admin.
